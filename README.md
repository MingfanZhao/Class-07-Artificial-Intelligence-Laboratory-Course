## 项目说明

这是 `Class-07-Artificial-Intelligence-Laboratory-Course` 的工程文件夹描述文件。

## 包含内容

- `vivado综合与实现简要说明.pdf`：包含 Vivado 软件的说明和介绍。
- `class_7_conv.rar`：包含实现卷积的加法器累加器。
- `MAC.zip`：课程提供的计算阵列电路的 Verilog 代码，供参考。

## 使用说明

- 大家解压文件，使用 Vivado 以工程的形式打开。
- 可以按照 `vivado综合与实现简要说明.pdf` 的描述进行综合实现等步骤。
- `MAC.zip` 中的输入输出位置支持并行度可调节设置。
- 大家可以根据需求设计具体规模的电路。
